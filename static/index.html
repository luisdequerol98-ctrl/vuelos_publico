        Avisos por Telegram
        1. En Telegram, abre @BotFather, escribe /newbot y sigue los pasos. Te dará un token.
        2. Pega el token aquí y pulsa Guardar.
        3. Abre tu bot nuevo en Telegram, pulsa Iniciar y escríbele «hola».
        4. Pulsa Detectar mi chat y luego Enviar prueba.
        Revisar con el PC apagado (GitHub)

        1. Entra en github.com (crea una cuenta gratuita si no tienes).
        2. Crea un repositorio vacío: botón New → nombre buscador-vuelos → Private (o Public: minutos ilimitados, pero tus viajes quedan a la vista) → Create repository.
        3. Crea un token: tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. En Repository access elige solo ese repositorio; en Permissions pon Actions, Contents, Secrets y Workflows en Read and write; caducidad: 1 año.
        4. Pega aquí el repositorio y el token y pulsa Conectar y subir. Tus alertas, tu historial y los datos de Telegram se copian a GitHub.

        Gratis: GitHub da 2.000 minutos al mes en repositorios privados. Desde GitHub, Google responde de forma irregular y hay que repetir consultas: cada revisión gasta de 2 a 10 minutos por alerta según lo amplio que sea el rango. Con 5 revisiones al día caben 1 o 2 alertas con rangos de un mes; con rangos cortos, más.

        Revisiones automáticas

        Cada medianoche se sortean las horas al azar dentro de ese horario. Si el ordenador está apagado o suspendido a esa hora, la revisión se pierde. Si sueles apagarlo por la noche, acota el horario.

        En GitHub cada día se eligen al azar las horas entre 8 huecos repartidos por el día (máximo 8 revisiones). GitHub suele arrancar con unos minutos de retraso, lo que añade más azar.
